# Asset licenses & provenance

The **source code** is MIT (see `LICENSE`). This file covers the **art assets**.

Every asset the demo currently ships is a **procedurally generated stand-in**, made
by a committed, reproducible pipeline under `tools/` and released under **CC0** (no
attribution required). No third-party art is bundled.

| Asset | License | Source / provenance |
|-------|---------|---------------------|
| `src/openglcontext_marble_demo/assets/grout_color.png`, `grout_normal.png` | CC0 | Generated by `tools/make_grout.py` — a 1 m tile albedo grid (dark grout lines) + matching tangent-space normal map. Regenerate with `python tools/make_grout.py`. |
| Marble & surface colours / metallic-roughness | CC0 | Defined numerically in `materials.py` (no texture files). |
| Environment lighting (reflections) | CC0 | The PBR image-based lighting uses OpenGLContext's built-in **procedural studio probe** (`OPENGLCONTEXT_IBL=full`); no HDR file is bundled. |
| HUD / overlay text | — | Rendered from OpenGLContext's bundled DejaVu Sans Mono texture atlas (see the engine's own licensing). |

## Stand-ins vs. desired finals (for review)

The demo is fully playable on the CC0 stand-ins above. These are the assets worth
sourcing to lift the visual quality, noted here for review:

1. **HDR environment map** — a real outdoor/studio `.hdr` panorama (e.g. a CC0
   Poly Haven sky) registered as the IBL environment would give the metal marbles a
   far richer reflection than the procedural studio probe. OpenGLContext already
   supports this via `HDRBackground` / `--environment`; wiring it into `run.py` is a
   one-liner once an asset is chosen. **License to confirm: CC0 preferred.**
2. **Surface PBR texture sets** — real tiling colour/normal/roughness maps for
   stone, metal grate, rubber, and ice (e.g. CC0 ambientCG sets) in place of the
   flat colours + procedural grout, for material realism.
3. **A marble "cage"/normal detail** — optional micro-normal or dirt map on the
   marble for a less perfectly-smooth look on the matte materials (wood, rubber).
4. **Audio** — rolling loop, impacts, bumper boing, finish jingle (out of scope for
   v1; the run loop has the hooks — win/lose/impact events — to drive them).

Each of these is additive; none is required for the demo to run.
